### Hi, I'm Mark McKellar

I build the software that gets medical test results from the lab to the doctor: LIMS (laboratory information
management systems), clinical result reporting, and the integrations in between. Most of my career has been in a
clinical genetics and oncology lab, owning systems end to end: database, server, APIs and user interface.

Outside work I build with private AI, models that run on my own hardware, and interactive data visualization.
